# 📖 الجزء الأول: الأساسيات (Chapters 1-4)

## 🔹 Chapter 1: Chemical Foundations (الأساسيات الكيميائية)

### 1. الطريقة العلمية (The Scientific Method)
```
الملاحظة (Observation) 
       ↓
الفرضية (Hypothesis) ← تخمين مدروس
       ↓
التجربة (Experiment) ← اختبار الفرضية
       ↓
إذا صحيحة ← نظرية (Theory) ← قانون (Law)
إذا خاطئة ← نبدأ من الأول
```

### 2. الأخطاء في القياس (Measurement Errors)

| نوع الخطأ | الوصف | مثال |
|-----------|-------|------|
| **Systematic Error** | خطأ في اتجاه واحد فقط | ميزان غير مضبوط يزيد 0.1g دائماً |
| **Random Error** | خطأ في الاتجاهين (±) | قراءة مختلفة كل مرة بنفس الجهاز |

### 3. الدقة والضبط (Accuracy vs Precision)
```
🎯 Accuracy (الدقة/الصلاحية): 
   - مدى قرب النتيجة من القيمة الصحيحة
   - مثال: الرمية اللي تصيب الهدف

🎯 Precision (الضبط/الموثوقية):
   - مدى تقارب النتائج مع بعضها
   - مثال: 3 رميات في نفس المكان (حتى لو مش في الهدف)
```

### 4. الأرقام المعنوية (Significant Figures) ⭐ مهم جداً

**القواعد:**
```
✅ كل الأرقام غير الصفر مهمة: 1.234 = 4 أرقام معنوية
✅ الأصفار بين أرقام مهمة: 1002 = 4 أرقام معنوية
✅ الأصفار قبل أول رقم غير صفر = مش مهمة: 0.001 = رقم معنوي واحد
✅ الأصفار بعد الفاصلة العشرية = مهمة: 0.200 = 3 أرقام معنوية
✅ الأصفار في آخر عدد صحيح = مش واضحة: 190 = 2 أو 3؟ (نستخدم scientific notation)
```

**Scientific Notation:**
```
50,600 يمكن كتابتها:
• 5.06 × 10⁴ ← 3 أرقام معنوية
• 5.060 × 10⁴ ← 4 أرقام معنوية
• 5.0600 × 10⁴ ← 5 أرقام معنوية
```

### 5. قواعد الحساب مع الأرقام المعنوية

```
➕ الجمع والطرح: 
   - النتيجة تأخذ أقل عدد من المنازل العشرية
   - مثال: 3.0 + 12.60 = 15.60 → 15.6 (منزلة عشرية واحدة)

✖️ الضرب والقسمة:
   - النتيجة تأخذ أقل عدد من الأرقام المعنوية
   - مثال: 3.0 × 12.60 = 37.8 → 38 (رقمين معنويين)

📊 اللوغاريتمات:
   - عدد الأرقام المعنوية في المدخل = عدد المنازل العشرية في الناتج
   - log(3.00) = 0.477 (3 أرقام معنوية ← 3 منازل عشرية)
```

### 6. تقريب الأرقام (Rounding Rules)
```
1. الرقم المراد حذفه > 5 ← نزيد الرقم السابق 1
   مثال: 12.6 → 13

2. الرقم المراد حذفه < 5 ← نترك الرقم السابق كما هو
   مثال: 12.4 → 12

3. الرقم = 5 وبعده أرقام غير صفر ← نزيد 1
   مثال: 12.51 → 13

4. الرقم = 5 وبعده أصفار فقط ← "قاعدة الزوجي"
   - إذا الرقم السابق فردي ← نزيد 1: 11.5 → 12
   - إذا الرقم السابق زوجي ← نتركه: 12.5 → 12
```

## 🔹 Chapter 2: Atoms, Molecules, and Ions

### 1. القوانين الأساسية (Fundamental Laws)

| القانون | الوصف | مثال |
|---------|-------|-------|
| **قانون حفظ الكتلة** | الكتلة لا تفنى ولا تستحدث | كتلة المتفاعلات = كتلة النواتج |
| **قانون النسب الثابتة** | المركب له نسبة كتلة ثابتة للعناصر | الماء دائماً 8/9 أكسجين، 1/9 هيدروجين |
| **قانون حفظ الطاقة** | الطاقة تتحول من شكل لآخر | طاقة كيميائية ← حرارة |
| **قانون النسب المتعددة** | نسب العناصر في مركبات مختلفة تكون أعداد صحيحة صغيرة | الميثان والإيثان |

### 2. نظرية دالتون الذرية (Dalton's Atomic Theory)
```
✅ كل العناصر مكونة من ذرات
✅ ذرات العنصر الواحد متطابقة
✅ المركبات تتكون من اتحاد الذرات
✅ التفاعلات الكيميائية تعيد ترتيب الذرات فقط (لا تتغير الذرات نفسها)
```

### 3. تركيب الذرة (Atomic Structure)

```
                    النواة (Nucleus)
                    ├── بروتونات (+) ← تحدد العنصر
                    └── نيوترونات (0) ← تحدد النظير
                    
                    الإلكترونات (-) ← تدور حول النواة
                    - كتلتها صغيرة جداً (1/1840 من البروتون)
                    - مسئولة عن التفاعلات الكيميائية
```

### 4. النظائر (Isotopes)
```
نفس العنصر ← نفس عدد البروتونات ← مختلف في النيوترونات

مثال: الكربون
• كربون-12: 6 بروتونات + 6 نيوترونات
• كربون-13: 6 بروتونات + 7 نيوترونات
• كربون-14: 6 بروتونات + 8 نيوترونات (مشع)
```

### 5. تسمية المركبات (Naming Compounds) ⭐ مهم

#### أ) المركبات الثنائية (Binary Compounds)

| النوع | الوصف | طريقة التسمية | مثال |
|-------|-------|--------------|-------|
| **Type I** | فلز له شحنة واحدة ثابتة | اسم الفلز + اسم اللافلز + ide | NaCl = Sodium chloride |
| **Type II** | فلز له أكثر من شحنة | اسم الفلز + (رقم روماني للشحنة) + اسم اللافلز + ide | FeCl₂ = Iron(II) chloride |
| **Type III** | لا فلز + لا فلز | بادئات (mono, di, tri...) + اسم العنصر الثاني + ide | CO₂ = Carbon dioxide |

**البادئات:**
```
1 = mono (تحذف مع أول عنصر)
2 = di
3 = tri
4 = tetra
5 = penta
6 = hexa
```

#### ب) المركبات مع أيونات متعددة الذرات (Polyatomic Ions)

```
⚡ احفظ الأيونات دي لأنها بتتكرر كتير:

الأيون | الاسم | الشحنة
-------|-------|---------
NH₄⁺ | Ammonium | +1
OH⁻ | Hydroxide | -1
NO₃⁻ | Nitrate | -1
NO₂⁻ | Nitrite | -1
SO₄²⁻ | Sulfate | -2
SO₃²⁻ | Sulfite | -2
CO₃²⁻ | Carbonate | -2
PO₄³⁻ | Phosphate | -3
ClO₃⁻ | Chlorate | -1
ClO₄⁻ | Perchlorate | -1
```

**قاعدة التسمية:**
```
• إذا الأيون ينتهي بـ -ate ← الحمض ينتهي بـ -ic acid
  مثال: SO₄²⁻ (sulfate) ← H₂SO₄ (sulfuric acid)

• إذا الأيون ينتهي بـ -ite ← الحمض ينتهي بـ -ous acid
  مثال: SO₃²⁻ (sulfite) ← H₂SO₃ (sulfurous acid)
```

#### ج) تسمية الأحماض (Naming Acids)

```
🔹 Binary Acids (H + nonmetal):
   prefix "hydro-" + اسم العنصر + "-ic acid"
   مثال: HCl = Hydrochloric acid

🔹 Oxyacids (H + O + element):
   -ate ion ← "-ic acid"
   -ite ion ← "-ous acid"
```

## 🔹 Chapter 3: Stoichiometry (الحسابات الكيميائية) ⭐⭐⭐ مهم جداً

### 1. المول (The Mole)
```
📌 تعريف: كمية المادة التي تحتوي على 6.022 × 10²³ وحدة (عدد أفوجادرو)

📌 الكتلة المولية (Molar Mass):
   - كتلة 1 مول من المادة بالجرام
   - تساوي الكتلة الذرية/الجزيئية ولكن بوحدة g/mol

مثال: 
• H₂O: (2×1) + 16 = 18 g/mol
• يعني 18 جرام من الماء = 1 مول = 6.022×10²³ جزيء
```

### 2. النسبة المئوية للكتلة (Mass Percent)
```
Mass % = (كتلة العنصر في 1 مول ÷ كتلة 1 مول من المركب) × 100%

مثال: نسبة الأكسجين في الماء:
• كتلة O في H₂O = 16 g
• كتلة H₂O = 18 g
• %O = (16÷18) × 100 = 88.9%
```

### 3. الصيغة الأولية والجزيئية (Empirical & Molecular Formula)

```
🔹 Empirical Formula:
   - أبسط نسبة صحيحة للذرات في المركب
   - مثال: C₂H₄ ← الصيغة الأولية: CH₂

🔹 Molecular Formula:
   - الصيغة الحقيقية للمركب
   - دائماً مضاعف صحيح للصيغة الأولية
   - مثال: C₂H₄ = (CH₂) × 2

📝 خطوات إيجاد الصيغة الأولية:
1. افترض 100g من العينة ← النسب المئوية تصبح جرامات
2. حول الجرامات لمولات (اقسم على الكتلة الذرية)
3. اقسم كل القيم على أصغر قيمة
4. اضرب في عدد صحيح لو احتجت لأعداد صحيحة
```

**مثال عملي:**
```
مركب يحتوي على 40% كربون، 6.7% هيدروجين، 53.3% أكسجين

1. افترض 100g:
   C: 40g, H: 6.7g, O: 53.3g

2. حول لمولات:
   C: 40÷12 = 3.33 mol
   H: 6.7÷1 = 6.7 mol
   O: 53.3÷16 = 3.33 mol

3. اقسم على الأصغر (3.33):
   C: 1, H: 2, O: 1

4. الصيغة الأولية: CH₂O
```

### 4. موازنة المعادلات الكيميائية (Balancing Equations)

```
⚖️ القاعدة: عدد ذرات كل عنصر يجب أن يكون متساوي في الطرفين

خطوات الموازنة:
1. ابدأ بالعناصر التي تظهر مرة واحدة في كل طرف
2. اترك الهيدروجين والأكسجين للآخر
3. استخدم معاملات (أرقام أمام المركبات) مش تغيير الصيغ

مثال: موازنة احتراق البروبان
❌ C₃H₈ + O₂ → CO₂ + H₂O

✅ C₃H₈ + 5O₂ → 3CO₂ + 4H₂O
   (3C, 8H, 10O في الطرفين)
```

### 5. المحدد للتفاعل (Limiting Reactant) ⭐ مهم

```
🎯 التعريف: المتفاعل الذي ينفد أولاً ويحدد كمية الناتج

📝 خطوات الحل:
1. حول الكميات المعطاة لمولات
2. استخدم المعادلة الموزونة لحساب ناتج كل متفاعل
3. المتفاعل الذي يعطي أقل ناتج ← هو المحدد

مثال: 
2H₂ + O₂ → 2H₂O
إذا عندك 4 mol H₂ و 1 mol O₂:
• H₂ يمكن أن ينتج: 4 mol H₂O
• O₂ يمكن أن ينتج: 2 mol H₂O ← أقل ← O₂ هو المحدد
```

### 6. المحصول (Yield)

```
📊 Theoretical Yield: أقصى كمية ناتج ممكنة (نظرياً)
📊 Actual Yield: الكمية الفعلية التي تحصل عليها في المعمل
📊 Percent Yield = (Actual ÷ Theoretical) × 100%

⚠️ Actual Yield دائماً أقل من Theoretical بسبب:
• تفاعلات جانبية
• فقدان أثناء النقل
• تفاعل غير كامل
```

## 🔹 Chapter 4: Continue Stoichiometry (المحاليل والتفاعلات)

### 1. قواعد الذوبان (Solubility Rules) ⭐ احفظها

```
✅ دائماً ذائبة (Always Soluble):
• أيونات المجموعة 1 (Li⁺, Na⁺, K⁺...)
• NH₄⁺ (أمونيوم)
• NO₃⁻ (نترات)
• CH₃COO⁻ (أسيتات)
• ClO₃⁻, ClO₄⁻ (كلورات)

✅ ذائبة عموماً مع استثناءات:
• Cl⁻, Br⁻, I⁻ ← غير ذائبة مع: Ag⁺, Pb²⁺, Hg₂²⁺
• SO₄²⁻ ← غير ذائبة مع: Ba²⁺, Pb²⁺, Ca²⁺, Sr²⁺

❌ غير ذائبة عموماً مع استثناءات:
• CO₃²⁻, PO₄³⁻, OH⁻ ← ذائبة فقط مع: المجموعة 1 و NH₄⁺
• OH⁻ ذائبة أيضاً مع: Ba²⁺, Ca²⁺ (قليلاً)
```

**اختصار للحفظ: NAG SAG**
```
N = Nitrate (NO₃⁻) ← دائماً ذائب
A = Acetate (CH₃COO⁻) ← دائماً ذائب
G = Group 1 ← دائماً ذائب
S = Sulfate (SO₄²⁻) ← ذائب عموماً
A = Ammonium (NH₄⁺) ← دائماً ذائب
G = Group 17 halides (Cl⁻, Br⁻, I⁻) ← ذائبة عموماً

استثناءات SAG: PMS
P = Pb²⁺, M = Hg₂²⁺, S = Ag⁺
```

### 2. الإلكتروليتات (Electrolytes)

```
🔋 Strong Electrolytes: تتأين 100% ← توصل كهرباء ممتاز
• أملاح ذائبة: NaCl, KNO₃
• أحماض قوية: HCl, HNO₃, H₂SO₄
• قواعد قوية: NaOH, KOH

🔋 Weak Electrolytes: تتأين جزئياً ← توصل كهرباء ضعيف
• أحماض ضعيفة: CH₃COOH, HF
• قواعد ضعيفة: NH₃

🔋 Non-electrolytes: لا تتأين ← لا توصل كهرباء
• سكر: C₆H₁₂O₆
• كحول: C₂H₅OH
```

### 3. أنواع التفاعلات (Types of Reactions)

| النوع | الوصف | مثال |
|-------|-------|-------|
| **Acid-Base** | نقل بروتون (H⁺) | HCl + NaOH → NaCl + H₂O |
| **Precipitation** | تكوين راسب | AgNO₃ + NaCl → AgCl↓ + NaNO₃ |
| **Redox** | نقل إلكترونات | Zn + Cu²⁺ → Zn²⁺ + Cu |
| **Combination** | اتحاد متفاعلين | 2H₂ + O₂ → 2H₂O |
| **Decomposition** | تفكك مركب | CaCO₃ → CaO + CO₂ |
| **Combustion** | احتراق مع O₂ | CH₄ + 2O₂ → CO₂ + 2H₂O |

### 4. التركيز (Concentration Units)

```
📐 Molarity (M) = مولات المذاب ÷ لتر المحلول
   M = mol/L ← الأكثر استخداماً

📐 Molality (m) = مولات المذاب ÷ كجم المذيب
   m = mol/kg ← تستخدم في خواص المحاليل

📐 Mass Percent = (كتلة المذاب ÷ كتلة المحلول) × 100%

📐 ppm = (mg solute ÷ kg solution) × 10⁶

📐 Mole Fraction (χ) = مولات المكون ÷ إجمالي المولات
```

### 5. التخفيف (Dilution)

```
🔄 القانون: M₁V₁ = M₂V₂

حيث:
• M₁ = التركيز قبل التخفيف
• V₁ = الحجم قبل التخفيف
• M₂ = التركيز بعد التخفيف
• V₂ = الحجم بعد التخفيف

⚠️ عدد مولات المذاب ثابت قبل وبعد التخفيف

مثال: 
كم لتر من 6M HCl نحتاج لعمل 500mL من 1.5M HCl؟
6 × V₁ = 1.5 × 0.5
V₁ = 0.125 L = 125 mL
```

# 📖 الجزء الثاني: الغازات والطاقة (Chapters 5-6)

## 🔹 Chapter 5: Gases (الغازات)

### 1. قوانين الغازات (Gas Laws)

```
🌡️ Boyle's Law (عند ثبوت T):
   P₁V₁ = P₂V₂ ← الضغط والحجم عكسيين

🌡️ Charles's Law (عند ثبوت P):
   V₁/T₁ = V₂/T₂ ← الحجم ودرجة الحرارة طرديين
   ⚠️ T دائماً بالكلفن: K = °C + 273

🌡️ Avogadro's Law (عند ثبوت P, T):
   V₁/n₁ = V₂/n₂ ← الحجم وعدد المولات طرديين

🌡️ Ideal Gas Law (القانون الشامل):
   PV = nRT
   
   حيث:
   • P = الضغط (atm)
   • V = الحجم (L)
   • n = عدد المولات
   • R = 0.08206 L·atm/mol·K
   • T = درجة الحرارة (K)
```

### 2. قانون دالتون للضغوط الجزئية

```
📊 P_total = P₁ + P₂ + P₃ + ...

📊 P_i = χ_i × P_total
   حيث χ = الكسر المولي للمكون

مثال: خليط من 2 mol N₂ و 3 mol O₂ عند ضغط كلي 5 atm:
• χ_N₂ = 2/5 = 0.4
• P_N₂ = 0.4 × 5 = 2 atm
```

### 3. النظرية الحركية للغازات (Kinetic Molecular Theory)

```
افتراضات الغاز المثالي:
1. حجم جزيئات الغاز = صفر
2. لا توجد قوى تجاذب بين الجزيئات
3. الجزيئات في حركة عشوائية مستمرة
4. التصادمات مرنة (لا فقدان في الطاقة)
5. متوسط الطاقة الحركية ∝ درجة الحرارة بالكلفن

📐 سرعة الجزيئات (RMS velocity):
   u_rms = √(3RT/M)
   حيث M = الكتلة المولية بـ kg/mol
```

### 4. قانون جراهام (Graham's Law)

```
🔄 للانبعاث (Effusion) والانتشار (Diffusion):

Rate₁/Rate₂ = √(M₂/M₁)

⚠️ الغاز الأخف ← أسرع في الحركة

مثال: أي أسرع، H₂ أم O₂؟
Rate_H₂/Rate_O₂ = √(32/2) = √16 = 4
← H₂ أسرع 4 مرات من O₂
```

### 5. الغازات الحقيقية (Real Gases)

```
⚠️ الغازات الحقيقية تنحرف عن المثالية عند:
• ضغط عالي ← حجم الجزيئات يصبح مهم
• درجة حرارة منخفضة ← قوى التجاذب تصبح مهمة

📐 معادلة فان دير فالس:
   [P + a(n/V)²] × (V - nb) = nRT
   
   حيث:
   • a = تصحيح لقوى التجاذب
   • b = تصحيح لحجم الجزيئات
```

## 🔹 Chapter 6: Thermochemistry (الكيمياء الحرارية)

### 1. الطاقة والقانون الأول (Energy & First Law)

```
🔋 القانون الأول: ΔE = q + w

حيث:
• ΔE = التغير في الطاقة الداخلية
• q = الحرارة (+ إذا دخلت للنظام، - إذا خرجت)
• w = الشغل (+ إذا عمل على النظام، - إذا عمل النظام)

⚠️ الطاقة دالة حالة ← تعتمد فقط على الحالة الابتدائية والنهائية
```

### 2. الشغل في الغازات (Work)

```
📐 w = -PΔV (عند ضغط ثابت)

• إذا تمدد الغاز (ΔV > 0) ← w سالب ← النظام يبذل شغل
• إذا انضغط الغاز (ΔV < 0) ← w موجب ← شغل يُبذل على النظام
```

### 3. المحتوى الحراري (Enthalpy, H)

```
🔥 H = E + PV ← دالة حالة

🔥 عند ضغط ثابت: ΔH = q_p (الحرارة المتبادلة)

🔥 أنواع التفاعلات:
• Exothermic: ΔH < 0 ← يطلق حرارة ← النظام يفقد طاقة
• Endothermic: ΔH > 0 ← يمتص حرارة ← النظام يكتسب طاقة
```

### 4. السعة الحرارية (Heat Capacity)

```
📐 q = m × C × ΔT

حيث:
• q = الحرارة (J)
• m = الكتلة (g)
• C = السعة الحرارية النوعية (J/g·°C)
• ΔT = التغير في درجة الحرارة

💡 للماء: C = 4.184 J/g·°C ← قيمة عالية ← الماء يمتص حرارة كتير
```

### 5. قانون هيس (Hess's Law) ⭐ مهم

```
🔄 ΔH للتفاعل الكلي = مجموع ΔH للخطوات

💡 لأن ΔH دالة حالة ← لا تعتمد على المسار

📝 قواعد:
1. إذا عكست التفاعل ← غير إشارة ΔH
2. إذا ضربت التفاعل في عدد ← اضرب ΔH في نفس العدد

مثال:
إذا: A → B, ΔH = +100 kJ
فإن: B → A, ΔH = -100 kJ
و: 2A → 2B, ΔH = +200 kJ
```

### 6. المحتوى الحراري للتكوين (Enthalpy of Formation)

```
📐 ΔH°_reaction = Σ(n × ΔH°_f products) - Σ(n × ΔH°_f reactants)

⚠️ ΔH°_f للعناصر في حالتها القياسية = 0

مثال: احتراق الميثان
CH₄ + 2O₂ → CO₂ + 2H₂O

ΔH° = [1×(-393.5) + 2×(-285.8)] - [1×(-74.8) + 2×(0)]
    = -965.1 + 74.8 = -890.3 kJ
```

### 7. المسعرات (Calorimeters)

```
🔬 Bomb Calorimeter:
• حجم ثابت ← يقيس ΔE
• يستخدم لقياس حرارة الاحتراق

🔬 Coffee-Cup Calorimeter:
• ضغط ثابت ← يقيس ΔH
• يستخدم للتفاعلات في المحاليل
```

# 📖 الجزء الثالث: الذرة والروابط (Chapters 7-10)

## 🔹 Chapter 7: Atomic Structure & Periodicity

### 1. الأعداد الكمومية (Quantum Numbers) ⭐ مهم

```
🔢 هناك 4 أعداد كمومية تصف الإلكترون:

1️⃣ Principal (n): مستوى الطاقة الرئيسي
   • قيم: 1, 2, 3, ...
   • كلما زاد n ← زادت الطاقة ← بعد أكبر عن النواة

2️⃣ Angular Momentum (l): شكل المدار
   • قيم: 0 إلى (n-1)
   • l=0 → s orbital (شكل كروي)
   • l=1 → p orbital (شكل دمبل)
   • l=2 → d orbital
   • l=3 → f orbital

3️⃣ Magnetic (m_l): اتجاه المدار في الفراغ
   • قيم: -l إلى +l
   • مثال: إذا l=1 ← m_l = -1, 0, +1 (3 مدارات p)

4️⃣ Spin (m_s): اتجاه دوران الإلكترون
   • قيم: +½ أو -½
```

### 2. التوزيع الإلكتروني (Electron Configuration)

```
📝 قواعد التوزيع:
1. Aufbau: املأ من الأقل طاقة للأعلى
2. Pauli: إلكترونين كحد أقصى في كل مدار، باتجاهين متعاكسين
3. Hund: املأ كل مدار في المستوى الفرعي بإلكترون واحد قبل الازدواج

📊 ترتيب المستويات الفرعية بالطاقة:
1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f...

💡 اختصار للحفظ:
↑↓ ← إلكترونين في كل مدار
أولاً املأ كل مدار بواحد (Hund)
```

**مثال: الحديد (Fe, Z=26)**
```
1s² 2s² 2p⁶ 3s² 3p⁶ 4s² 3d⁶
أو: [Ar] 4s² 3d⁶
```

### 3. الاستثناءات في التوزيع الإلكتروني

```
⚠️ بعض العناصر "تسرق" إلكترون من 4s لملء أو نصف ملء 3d:

العنصر | المتوقع | الفعلي | السبب
-------|---------|--------|--------
Cr (24) | [Ar] 4s² 3d⁴ | [Ar] 4s¹ 3d⁵ | نصف ملء 3d أكثر استقراراً
Cu (29) | [Ar] 4s² 3d⁹ | [Ar] 4s¹ 3d¹⁰ | ملء 3d تماماً أكثر استقراراً
```

### 4. الاتجاهات في الجدول الدوري (Periodic Trends)

```
📈 Electronegativity (الكهروسالبية):
• تزيد ← لليمين ولأعلى
• F هي الأعلى ← Fr هي الأقل

📈 Ionization Energy (طاقة التأين):
• الطاقة اللازمة لنزع إلكترون
• تزيد ← لليمين ولأعلى
• الاستثناء: Be > B, N > O (بسبب استقرار نصف/كامل المستوى)

📈 Atomic Radius (نصف القطر الذري):
• يزيد ← لليسار ولأسفل
• الأيون الموجب أصغر من الذرة ← فقد إلكترونات
• الأيون السالب أكبر من الذرة ← اكتسب إلكترونات

📈 Electron Affinity (الألفة الإلكترونية):
• الطاقة المنطلقة عند اكتساب إلكترون
• تزيد ← لليمين (بشكل عام)
```

## 🔹 Chapter 8-10: Bonding (الروابط الكيميائية)

### 1. أنواع الروابط

```
🔗 Ionic Bond (أيونية):
• نقل إلكترونات ← تكوين أيونات
• بين فلز ولا فلز
• قوية جداً ← درجات انصهار عالية
• مثال: NaCl

🔗 Covalent Bond (تساهمية):
• مشاركة إلكترونات
• بين لا فلزات
• غير قطبية: نفس الكهروسالبية (H₂)
• قطبية: فرق كهروسالبية (HCl)

🔗 Metallic Bond (فلزية):
• "بحر" من الإلكترونات الحرة
• تفسر التوصيل الكهربائي والمطيلية

🔗 Hydrogen Bond (هيدروجينية):
• بين H مرتبط بـ N, O, أو F ← وزوج حر على ذرة أخرى
• أضعف من التساهمية لكن أقوى من فان دير فالس
• تفسر ارتفاع غليان الماء
```

### 2. تركيب لويس (Lewis Structures) ⭐ مهم

```
📝 خطوات الرسم:
1. احسب إجمالي إلكترونات التكافؤ
2. ضع الذرة الأقل كهروسالبية في الوسط (ما عدا H)
3. كون روابط أحادية بين الذرات
4. وزع الإلكترونات المتبقية لإكمال الثمانيات
5. إذا احتجت، كون روابط مزدوجة/ثلاثية

⚠️ قاعدة الثمانية: معظم الذرات تريد 8 إلكترونات في غلاف التكافؤ

استثناءات:
• H, He ← يريدان 2 إلكترونات فقط
• B, Be ← يمكن أن يكونا بأقل من 8
• P, S, Cl (من الدورة 3+) ← يمكن أن يكونا بأكثر من 8 (d-orbitals)
```

### 3. الشحنة الرسمية (Formal Charge)

```
📐 FC = (Valence e⁻) - (Nonbonding e⁻) - ½(Bonding e⁻)

💡 التركيب الأفضل = أقل شحنات رسمية، والشحنات السالبة على الذرات الأكثر كهروسالبية

مثال: CO₂
   O=C=O ← أفضل من: O-C≡O
   لأن الشحنات الرسمية = 0 في الأول
```

### 4. الرنين (Resonance)

```
🔄 عندما يمكن رسم أكثر من تركيب لويس صحيح لنفس الجزيء

💡 الجزيء الحقيقي = متوسط (هجين) لجميع تراكيب الرنين
   ← ليس يتذبذب بينها!

مثال: O₃ (الأوزون)
   له تركيبان رنينيان ← الرابطة بين O-O متوسطة بين أحادية ومزدوجة
```

### 5. نظرية VSEPR (شكل الجزيئات)

```
🎯 الفكرة: أزواج الإلكترونات تتنافر ← تأخذ أبعد مسافة ممكنة

| أزواج حول الذرة المركزية | الشكل | الزوايا | مثال |
|------------------------|--------|---------|--------|
| 2 (0 lone pairs) | Linear | 180° | CO₂ |
| 3 (0 lone pairs) | Trigonal Planar | 120° | BF₃ |
| 3 (1 lone pair) | Bent | <120° | SO₂ |
| 4 (0 lone pairs) | Tetrahedral | 109.5° | CH₄ |
| 4 (1 lone pair) | Trigonal Pyramidal | <109.5° | NH₃ |
| 4 (2 lone pairs) | Bent | <109.5° | H₂O |
| 5 (0 lone pairs) | Trigonal Bipyramidal | 90°, 120° | PCl₅ |
| 6 (0 lone pairs) | Octahedral | 90° | SF₆ |
```

### 6. التهجين (Hybridization)

```
🔄 خلط المدارات الذرية لتكوين مدارات مهجنة جديدة

| التهجين | المدارات المخلوطة | الشكل | الزوايا | مثال |
|---------|------------------|--------|---------|--------|
| sp | 1s + 1p | Linear | 180° | BeCl₂ |
| sp² | 1s + 2p | Trigonal Planar | 120° | BF₃ |
| sp³ | 1s + 3p | Tetrahedral | 109.5° | CH₄ |
| sp³d | 1s + 3p + 1d | Trigonal Bipyramidal | 90°, 120° | PCl₅ |
| sp³d² | 1s + 3p + 2d | Octahedral | 90° | SF₆ |

💡 طريقة سريعة: عد "مناطق الإلكترون" حول الذرة
• 2 مناطق ← sp
• 3 مناطق ← sp²
• 4 مناطق ← sp³
• 5 مناطق ← sp³d
• 6 مناطق ← sp³d²
```

### 7. القوى بين الجزيئات (Intermolecular Forces)

```
📊 من الأضعف للأقوى:

1️⃣ London Dispersion Forces:
   • في كل الجزيئات
   • ناتجة عن توزيع إلكتروني مؤقت غير متماثل
   • تزداد مع: حجم الجزيء، مساحة السطح

2️⃣ Dipole-Dipole Forces:
   • في الجزيئات القطبية فقط
   • تجاذب بين الأقطاب المختلفة

3️⃣ Hydrogen Bonding:
   • حالة خاصة قوية من dipole-dipole
   • تتطلب: H مرتبط بـ N, O, أو F
   • تفسر: ارتفاع غليان الماء، تركيب DNA

💡 تأثير القوى على الخواص الفيزيائية:
• قوى أقوى ← غليان أعلى، لزوجة أعلى، توتر سطحي أعلى، ضغط بخار أقل
```

# 📖 الجزء الرابع: المحاليل والحركية (Chapters 11-12)

## 🔹 Chapter 11: Properties of Solutions

### 1. الذوبانية (Solubility)

```
🎯 "Like dissolves like"
• المواد القطبية تذوب في المذيبات القطبية (الماء)
• المواد غير القطبية تذوب في المذيبات غير القطبية (الهكسان)

🌡️ تأثير درجة الحرارة:
• معظم المواد الصلبة: تزيد الذوبانية بزيادة الحرارة
• الغازات: تقل الذوبانية بزيادة الحرارة ← لذلك المشروبات الغازية تفقد الفوران عند الدفء

📈 تأثير الضغط (للغازات فقط - Henry's Law):
• C = k × P
• زيادة الضغط ← زيادة ذوبانية الغاز
```

### 2. ضغط البخار وقانون راولت

```
📐 Raoult's Law (للمحاليل المثالية):
   P_solution = χ_solvent × P°_solvent

حيث:
• χ = الكسر المولي للمذيب
• P° = ضغط بخار المذيب النقي

💡 إضافة مذاب غير متطاير ← تقلل ضغط البخار
```

### 3. الخواص الجامعة (Colligative Properties) ⭐ مهم

```
🎯 تعتمد فقط على عدد جزيئات المذاب، ليس نوعها

📊 Van't Hoff Factor (i):
• i = عدد الجسيمات التي يتفكك إليها المذاب
• NaCl ← i = 2 (Na⁺ + Cl⁻)
• CaCl₂ ← i = 3 (Ca²⁺ + 2Cl⁻)
• Glucose ← i = 1 (لا يتفكك)

🔹 1. خفض ضغط البخار:
   ΔP = χ_solute × P°_solvent

🔹 2. ارتفاع درجة الغليان:
   ΔT_b = i × K_b × m
   • K_b = ثابت ارتفاع الغليان (للماء = 0.512 °C/m)
   • m = المولالية

🔹 3. انخفاض درجة التجمد:
   ΔT_f = i × K_f × m
   • K_f = ثابت انخفاض التجمد (للماء = 1.86 °C/m)

🔹 4. الضغط الأسموزي:
   Π = i × M × R × T
   • M = المولارية
   • مهم في الخلايا البيولوجية
```

**مثال عملي:**
```
ما درجة تجمد محلول 0.5 m من NaCl في الماء؟
• i = 2 لـ NaCl
• ΔT_f = 2 × 1.86 × 0.5 = 1.86°C
• درجة التجمد = 0 - 1.86 = -1.86°C
```

## 🔹 Chapter 12: Kinetics (حركية التفاعلات)

### 1. معدل التفاعل (Reaction Rate)

```
📐 Rate = -Δ[Reactant]/Δt = +Δ[Product]/Δt

⚠️ الإشارة السالبة للمتفاعلات لأن تركيزها يقل

مثال: 2A → B
• Rate = -½ Δ[A]/Δt = +Δ[B]/Δt
```

### 2. قانون المعدل (Rate Law) ⭐ مهم جداً

```
📐 Rate = k [A]^m [B]^n

حيث:
• k = ثابت المعدل (يعتمد على الحرارة)
• m, n = رتبة التفاعل بالنسبة لكل مادة (تحدد تجريبياً!)
• الرتبة الكلية = m + n

💡 الرتبة لا علاقة لها بمعاملات المعادلة الموزونة!
```

### 3. تحديد رتبة التفاعل من البيانات

```
📊 طريقة المقارنة:
1. ابحث عن تجربتين يختلف فيهما تركيز مادة واحدة فقط
2. قارن التغير في التركيز مع التغير في المعدل

مثال:
| Exp | [A] (M) | Rate (M/s) |
|-----|---------|------------|
| 1   | 0.1     | 0.02       |
| 2   | 0.2     | 0.08       |

• [A] ضاعف (×2)، Rate زاد 4 مرات (×4)
• 2^m = 4 ← m = 2 ← الرتبة بالنسبة لـ A = 2
```

### 4. قوانين المعدل المتكاملة (Integrated Rate Laws)

```
| الرتبة | قانون المعدل | القانون المتكامل | نصف العمر | رسم خطي |
|--------|-------------|-----------------|-----------|---------|
| 0 | Rate = k | [A] = -kt + [A]₀ | t₁/₂ = [A]₀/2k | [A] vs t |
| 1 | Rate = k[A] | ln[A] = -kt + ln[A]₀ | t₁/₂ = 0.693/k | ln[A] vs t |
| 2 | Rate = k[A]² | 1/[A] = kt + 1/[A]₀ | t₁/₂ = 1/k[A]₀ | 1/[A] vs t |

💡 نصف العمر للرتبة الأولى: ثابت (لا يعتمد على التركيز!)
```

### 5. طاقة التنشيط ومعادلة أرهينيوس

```
🔑 Activation Energy (E_a):
• الحد الأدنى من الطاقة اللازمة لحدوث التفاعل
• E_a أعلى ← تفاعل أبطأ

📐 Arrhenius Equation:
   k = A × e^(-E_a/RT)
   
   أو في صورة لوغاريتمية:
   ln(k) = ln(A) - E_a/(RT)

💡 من الرسم: ln(k) vs 1/T
• الميل = -E_a/R
• يمكن حساب E_a من تجربتين:
   ln(k₂/k₁) = -E_a/R × (1/T₂ - 1/T₁)
```

### 6. آليات التفاعل (Reaction Mechanisms)

```
🔄 معظم التفاعلات تحدث في خطوات متعددة

🎯 Rate-Determining Step (RDS):
• أبطأ خطوة في الآلية
• تحدد قانون المعدل الكلي

💡 شروط الآلية المقبولة:
1. مجموع الخطوات = المعادلة الكلية
2. قانون المعدل المشتق = قانون المعدل التجريبي

مثال:
الخطوة 1: NO₂ + NO₂ → NO + NO₃ (بطيئة ← RDS)
الخطوة 2: NO₃ + CO → NO₂ + CO₂ (سريعة)
________________________
الكلي: NO₂ + CO → NO + CO₂

Rate = k[NO₂]² (من الخطوة البطيئة فقط)
```

### 7. العوامل المؤثرة على معدل التفاعل

```
📈 تزيد المعدل:
• زيادة التركيز ← تصادمات أكثر
• زيادة الحرارة ← طاقة حركية أعلى، أكثر جزيئات تتجاوز E_a
• زيادة مساحة السطح (للمواد الصلبة)
• إضافة محفز

🔬 Catalysts (المحفزات):
• تقلل E_a ← تزيد المعدل
• لا تستهلك في التفاعل
• لا تغير ΔH أو موضع الاتزان
• نوعان: متجانس (نفس الطور) وغير متجانس (طور مختلف)
```

# 📖 الجزء الخامس: الاتزان والأحماض (Chapters 13-15)

## 🔹 Chapter 13: Chemical Equilibrium

### 1. مفهوم الاتزان (Equilibrium Concept)

```
🔄 التفاعل العكوس: A + B ⇌ C + D

⚖️ عند الاتزان:
• معدل التفاعل الأمامي = معدل التفاعل العكسي
• تراكيز المواد ثابتة (لكن التفاعل مستمر!)
• يمكن الوصول للاتزان من أي اتجاه

💡 الاتزان ديناميكي ← جزيئات تتحول في الاتجاهين بنفس المعدل
```

### 2. ثابت الاتزان (Equilibrium Constant)

```
📐 للتفاعل: aA + bB ⇌ cC + dD

K_c = [C]^c [D]^d / [A]^a [B]^b

K_p = (P_C)^c (P_D)^d / (P_A)^a (P_B)^b

⚠️ قواعد مهمة:
• لا تدخل المواد الصلبة أو السوائل النقية في التعبير
• الوحدات: K_c بـ M، K_p بـ atm
• العلاقة: K_p = K_c (RT)^Δn
  حيث Δn = مولات الغازات في النواتج - مولات الغازات في المتفاعلات
```

### 3. تفسير قيمة K

```
📊 K >> 1 ← الاتزان يميل للنواتج (نواتج أكثر)
📊 K << 1 ← الاتزان يميل للمتفاعلات (متفاعلات أكثر)
📊 K ≈ 1 ← كميات متقاربة من الطرفين

💡 تغيير المعادلة يغير K:
• عكس التفاعل: K' = 1/K
• ضرب المعادلة في n: K' = K^n
• جمع تفاعلين: K_total = K₁ × K₂
```

### 4. حاصل التفاعل (Reaction Quotient, Q)

```
📐 Q له نفس صيغة K لكن باستخدام التراكيز الأولية (غير الاتزانية)

🎯 مقارنة Q مع K:
• Q < K ← التفاعل يتجه لليمين (يزيد النواتج)
• Q > K ← التفاعل يتجه لليسار (يزيد المتفاعلات)
• Q = K ← النظام في اتزان
```

### 5. مبدأ لوشاتلييه (Le Châtelier's Principle) ⭐ مهم

```
🎯 "إذا أُحدث تغير في نظام في اتزان، يتجه النظام لمقاومة هذا التغير"

| التغير | اتجاه الانزياح |
|--------|---------------|
| زيادة [متفاعل] | لليمين ← يستهلك المتفاعل |
| زيادة [ناتج] | لليسار ← يستهلك الناتج |
| زيادة الضغط (لغازات) | للاتجاه ذو مولات غاز أقل |
| زيادة الحجم (تقليل ضغط) | للاتجاه ذو مولات غاز أكثر |
| زيادة الحرارة (تفاعل ماص للحرارة) | لليمين ← يمتص الحرارة |
| زيادة الحرارة (تفاعل طارد للحرارة) | لليسار ← يقلل الحرارة |
| إضافة محفز | لا يغير موضع الاتزان، يسرع الوصول له |
```

**مثال:**
```
لتفاعل: N₂ + 3H₂ ⇌ 2NH₃ + حرارة (طارد للحرارة)

• زيادة [N₂] ← يمين
• إزالة NH₃ ← يمين
• زيادة الضغط ← يمين (4 مولات غاز ← 2 مولات)
• زيادة الحرارة ← يسار (لأن التفاعل طارد)
```

### 6. جدول ICE ⭐ أداة أساسية للحل

```
📝 I = Initial (التركيز الابتدائي)
📝 C = Change (التغير)
📝 E = Equilibrium (تركيز الاتزان)

مثال: H₂ + I₂ ⇌ 2HI, K = 50
الابتدائي: [H₂]=1M, [I₂]=1M, [HI]=0

        H₂    +    I₂    ⇌    2HI
I       1          1           0
C       -x         -x         +2x
E      1-x        1-x         2x

K = (2x)² / (1-x)² = 50
حل المعادلة ← أوجد x ← احسب التراكيز عند الاتزان
```

## 🔹 Chapter 14: Acids and Bases

### 1. نظريات الأحماض والقواعد

```
🔬 Arrhenius:
• Acid: ينتج H⁺ في الماء (HCl)
• Base: ينتج OH⁻ في الماء (NaOH)

🔬 Brønsted-Lowry ⭐ الأكثر استخداماً:
• Acid: مانح للبروتون (H⁺)
• Base: مستقبل للبروتون

مثال: 
   HCl + H₂O ⇌ Cl⁻ + H₃O⁺
   Acid₁  Base₂   Base₁   Acid₂
   
   ← أزواج مترافقة: HCl/Cl⁻ و H₃O⁺/H₂O

🔬 Lewis:
• Acid: مستقبل زوج إلكتروني
• Base: مانح زوج إلكتروني
```

### 2. قوة الأحماض والقواعد

```
🔹 Strong Acids (تتأين 100%):
• HCl, HBr, HI
• HNO₃
• H₂SO₄ (الخطوة الأولى فقط)
• HClO₄

🔹 Strong Bases:
• هيدروكسيدات المجموعة 1 و 2 الثقيلة: NaOH, KOH, Ba(OH)₂

💡 Weak acids/bases: تتأين جزئياً ← لها ثابت تأين (Ka أو Kb)
```

### 3. ثابت التأين (Ka and Kb)

```
📐 للأحماض الضعيفة: HA ⇌ H⁺ + A⁻
   Ka = [H⁺][A⁻] / [HA]

📐 للقواعد الضعيفة: B + H₂O ⇌ BH⁺ + OH⁻
   Kb = [BH⁺][OH⁻] / [B]

💡 العلاقة: Ka × Kb = Kw = 1.0 × 10⁻¹⁴ (عند 25°C)

📊 pKa = -log(Ka) ← كلما قل pKa ← زاد حمض
📊 pKb = -log(Kb) ← كلما قل pKb ← زاد قاعدة
```

### 4. مقياس pH و pOH

```
📐 pH = -log[H⁺]
📐 pOH = -log[OH⁻]
📐 pH + pOH = 14 (عند 25°C)

| المحلول | [H⁺] | pH |
|---------|------|-----|
| حمضي قوي | > 10⁻⁷ | < 7 |
| متعادل | = 10⁻⁷ | = 7 |
| قاعدي قوي | < 10⁻⁷ | > 7 |
```

### 5. حسابات pH للأحماض الضعيفة ⭐ مهم

```
📝 خطوات الحل:
1. اكتب معادلة التأين
2. ضع جدول ICE
3. استخدم Ka لحساب [H⁺]
4. احسب pH

مثال: 0.1 M CH₃COOH, Ka = 1.8×10⁻⁵

CH₃COOH ⇌ H⁺ + CH₃COO⁻
I    0.1       0       0
C    -x       +x      +x
E   0.1-x      x       x

Ka = x²/(0.1-x) ≈ x²/0.1 = 1.8×10⁻⁵  (نفترض x << 0.1)
x² = 1.8×10⁻⁶
x = [H⁺] = 1.34×10⁻³ M
pH = -log(1.34×10⁻³) = 2.87

⚠️ تحقق من الافتراض: 1.34×10⁻³ / 0.1 = 1.34% < 5% ← الافتراض صحيح
```

### 6. الأحماض متعددة البروتونات (Polyprotic Acids)

```
🔄 تتأين على خطوات، كل خطوة لها Ka مختلف

مثال: H₃PO₄
1. H₃PO₄ ⇌ H⁺ + H₂PO₄⁻, Ka₁ = 7.5×10⁻³
2. H₂PO₄⁻ ⇌ H⁺ + HPO₄²⁻, Ka₂ = 6.2×10⁻⁸
3. HPO₄²⁻ ⇌ H⁺ + PO₄³⁻, Ka₃ = 4.8×10⁻¹³

💡 Ka₁ >> Ka₂ >> Ka₃ ← معظم H⁺ من الخطوة الأولى
← يمكن تجاهل الخطوات التالية في حساب pH تقريباً
```

### 7. خواص الأملاح في الماء

```
🔍 ملح من: | محلول يكون: | مثال |
|----------|-------------|--------|
| حمض قوي + قاعدة قوية | متعادل (pH=7) | NaCl |
| حمض قوي + قاعدة ضعيفة | حمضي (pH<7) | NH₄Cl |
| حمض ضعيف + قاعدة قوية | قاعدي (pH>7) | NaF |
| حمض ضعيف + قاعدة ضعيفة | يعتمد على Ka vs Kb | NH₄CN |

💡 القاعدة: الأيون المترافق لحمض ضعيف ← قاعدة
          الأيون المترافق لقاعدة ضعيفة ← حمض
```

## 🔹 Chapter 15: Buffer Solutions (محاليل البفر)

### 1. ما هو البفر؟

```
🛡️ Buffer Solution: محلول يقاوم تغيرات pH عند إضافة حمض أو قاعدة

📦 يتكون من:
• حمض ضعيف + ملحه (قاعده المرافقة)
  مثال: CH₃COOH + CH₃COONa
• أو: قاعدة ضعيفة + ملحها (حمضها المرافق)
  مثال: NH₃ + NH₄Cl
```

### 2. كيف يعمل البفر؟

```
🔄 عند إضافة H⁺ (حمض):
   A⁻ + H⁺ → HA
   ← الأيون المترافق "يمتص" البروتونات

🔄 عند إضافة OH⁻ (قاعدة):
   HA + OH⁻ → A⁻ + H₂O
   ← الحمض الضعيف "يمتص" الهيدروكسيد

💡 البفر يعمل طالما كمية الحمض/القاعدة المضافة << كمية مكونات البفر
```

### 3. معادلة هندرسون-هاسلبالك ⭐ مهمة جداً

```
📐 للأحماض: pH = pKa + log([A⁻]/[HA])

📐 للقواعد: pOH = pKb + log([BH⁺]/[B])

💡 عندما [A⁻] = [HA] ← pH = pKa ← أفضل قدرة تنظيمية

مثال: محلول 0.1 M CH₃COOH و 0.1 M CH₃COONa
• pKa لـ CH₃COOH = 4.74
• pH = 4.74 + log(0.1/0.1) = 4.74 + 0 = 4.74
```

### 4. سعة البفر (Buffer Capacity)

```
📊 قدرة البفر على مقاومة تغيرات pH تعتمد على:
1. التركيز الكلي لمكونات البفر ← كلما زاد ← زادت السعة
2. نسبة [A⁻]/[HA] ← الأفضل عندما قريبة من 1 (بين 0.1 و 10)

🎯 أفضل مدى للبفر: pH = pKa ± 1
```

### 5. المعايرة (Titration) ⭐ مهم

```
📈 منحنى المعايرة: pH vs Volume of titrant

🔹 Strong Acid + Strong Base:
• نقطة التكافؤ عند pH = 7
• تغير حاد في المنطقة المحيطة بنقطة التكافؤ

🔹 Weak Acid + Strong Base:
• نقطة التكافؤ عند pH > 7
• منطقة بفر قبل نقطة التكافؤ
• عند نصف نقطة التكافؤ: pH = pKa

🔹 Strong Acid + Weak Base:
• نقطة التكافؤ عند pH < 7

📐 عند نقطة التكافؤ:
   M_acid × V_acid = M_base × V_base (مع مراعاة المعاملات)
```

### 6. الدلائل (Indicators)

```
🎨 Indicator: حمض/قاعدة ضعيفة لها لون مختلف في الصورة المتأينة وغير المتأينة

🔄 يتغير لونه عند: pH ≈ pKa للدليل

💡 اختر دليل يتغير لونه عند نقطة تكافؤ التفاعل

مثال:
• Phenolphthalein: عديم اللون ← وردي عند pH 8.2-10
  ← مناسب لمعايرة حمض ضعيف مع قاعدة قوية
• Methyl orange: أحمر ← أصفر عند pH 3.1-4.4
  ← مناسب لمعايرة حمض قوي مع قاعدة ضعيفة
```

# 📖 الجزء السادس: مواضيع متقدمة (Chapters 16-18)

## 🔹 Chapter 16: Complex Ion Equilibrium

### 1. حاصل الإذابة (Ksp)

```
📐 للتفاعل: MX(s) ⇌ M⁺(aq) + X⁻(aq)
   Ksp = [M⁺][X⁻]

💡 Ksp ثابت عند درجة حرارة معينة ← يدل على الذوبانية

📊 مقارنة مع Q:
• Q < Ksp ← غير مشبع ← لا راسب
• Q = Ksp ← مشبع ← عند الاتزان
• Q > Ksp ← فوق مشبع ← يتكون راسب
```

### 2. الذوبانية وحسابها

```
📝 مثال: حساب ذوبانية AgCl (Ksp = 1.8×10⁻¹⁰)

AgCl(s) ⇌ Ag⁺ + Cl⁻
Ksp = [Ag⁺][Cl⁻] = s × s = s²
s = √(1.8×10⁻¹⁰) = 1.34×10⁻⁵ M

🔄 مع أيون مشترك (Common Ion Effect):
إذا أضفنا NaCl ← [Cl⁻] يزيد ← [Ag⁺] يقل ← ذوبانية AgCl تقل
```

### 3. الترسيب الانتقائي (Selective Precipitation)

```
🎯 فصل أيونات بإضافة كاشف يرسب أحدها فقط

مثال: فصل Ag⁺ عن Pb²⁺ باستخدام Cl⁻:
• Ksp(AgCl) = 1.8×10⁻¹⁰ ← يرسب أولاً
• Ksp(PbCl₂) = 1.7×10⁻⁵ ← يرسب لاحقاً

💡 احسب [Cl⁻] اللازمة لترسيب كل أيون ← اختر قيمة بينهما
```

### 4. تكوين المعقدات (Complex Ions)

```
🔄 المعقد: أيون فلزي + ليجندات (مانحة أزواج إلكترونية)

مثال: Ag⁺ + 2NH₃ ⇌ [Ag(NH₃)₂]⁺
   Kf = [Ag(NH₃)₂⁺] / ([Ag⁺][NH₃]²) ← ثابت التكوين

💡 Kf كبير ← معقد مستقر ← يزيد ذوبانية الأملاح
```

## 🔹 Chapter 17: Thermodynamics (Spontaneity, Entropy, Free Energy)

### 1. القوانين الثلاثة للديناميكا الحرارية

```
🔹 القانون الأول: حفظ الطاقة
   ΔE = q + w

🔹 القانون الثاني ⭐:
   • أي عملية تلقائية تزيد إنتروبيا الكون
   • ΔS_universe = ΔS_system + ΔS_surroundings > 0

🔹 القانون الثالث:
   • إنتروبيا بلورة مثالية عند 0 K = 0
```

### 2. الإنتروبيا (Entropy, S)

```
🎯 مقياس للعشوائية/عدد التوزيعات الممكنة

📈 تزيد الإنتروبيا عندما:
• صلب ← سائل ← غاز
• عدد مولات الغازات يزيد في التفاعل
• درجة الحرارة تزيد
• حجم النظام يزيد

💡 ΔS°_reaction = ΣS°(products) - ΣS°(reactants)
```

### 3. طاقة جيبس الحرة (Gibbs Free Energy, G) ⭐⭐⭐ مهم جداً

```
📐 ΔG = ΔH - TΔS

🎯 تفسير ΔG:
• ΔG < 0 ← تلقائي (spontaneous)
• ΔG = 0 ← في اتزان
• ΔG > 0 ← غير تلقائي

📊 العلاقة مع K:
   ΔG° = -RT ln(K)
   • K > 1 ← ΔG° < 0 ← تلقائي
   • K < 1 ← ΔG° > 0 ← غير تلقائي
```

### 4. جدول تلقائية التفاعلات

```
| ΔH | ΔS | ΔG = ΔH - TΔS | التلقائية |
|-----|-----|---------------|-----------|
| - (طارد) | + (يزيد عشوائية) | دائماً سالب | تلقائي عند كل T |
| + (ماص) | - (يقلل عشوائية) | دائماً موجب | غير تلقائي عند كل T |
| - (طارد) | - (يقلل عشوائية) | سالب عند T منخفضة | تلقائي عند درجات حرارة منخفضة |
| + (ماص) | + (يزيد عشوائية) | سالب عند T مرتفعة | تلقائي عند درجات حرارة مرتفعة |
```

### 5. الشغل الأقصى

```
💡 ΔG = أقصى شغل مفيد يمكن الحصول عليه من التفاعل عند ثبوت P, T

⚠️ في الواقع: الشغل الفعلي < ΔG بسبب الاحتكاك والضياع
```

## 🔹 Chapter 18: Electrochemistry (الكهروكيمياء)

### 1. الأكسدة والاختزال (Redox)

```
🎯 OIL RIG:
• Oxidation Is Loss (of electrons) ← زيادة في رقم الأكسدة
• Reduction Is Gain (of electrons) ← نقص في رقم الأكسدة

🎯 AnOx RedCat:
• Anode: Oxidation occurs
• Cathode: Reduction occurs
```

### 2. موازنة تفاعلات الأكسدة والاختزال (Half-Reaction Method)

```
📝 خطوات الموازنة في وسط حمضي:
1. اكتب نصفي التفاعل (أكسدة واختزال)
2. وازن الذرات عدا H و O
3. وازن O بإضافة H₂O
4. وازن H بإضافة H⁺
5. وازن الشحنة بإضافة e⁻
6. اضرب النصفين لتساوي الإلكترونات
7. اجمع النصفين واحذف المتكرر

مثال: موازنة: MnO₄⁻ + Fe²⁺ → Mn²⁺ + Fe³⁺ (في وسط حمضي)

الاختزال: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O
الأكسدة: Fe²⁺ → Fe³⁺ + e⁻ (×5)
________________________
الكلي: MnO₄⁻ + 8H⁺ + 5Fe²⁺ → Mn²⁺ + 4H₂O + 5Fe³⁺
```

### 3. الخلايا الجلفانية (Voltaic/Galvanic Cells)

```
🔋 تحول الطاقة الكيميائية ← كهربائية (تفاعل تلقائي)

📊 مكونات الخلية:
• Anode (-): حيث تحدث الأكسدة ← يفقد إلكترونات
• Cathode (+): حيث يحدث الاختزال ← يكتسب إلكترونات
• Salt Bridge: يكمل الدائرة ويحافظ على التعادل الكهربي
• External circuit: تدفق الإلكترونات من anode إلى cathode

📐 E°_cell = E°_cathode - E°_anode

💡 E°_cell > 0 ← تفاعل تلقائي
```

### 4. جهود الاختزال القياسية

```
📊 جدول جهود الاختزال (Standard Reduction Potentials):

• كلما زاد E° ← المادة أكثر ميلاً للاختزال ← مؤكسد أقوى
• المادة ذات أقل E° ← مختزل أقوى

أمثلة:
• F₂ + 2e⁻ → 2F⁻, E° = +2.87 V ← أقوى مؤكسد
• Li⁺ + e⁻ → Li, E° = -3.05 V ← أقوى مختزل

💡 التفاعل التلقائي: المؤكسد الأعلى في الجدول يختزل، والمختزل الأقل يتأكسد
```

### 5. معادلة نيرنست (Nernst Equation) ⭐ مهم

```
📐 للتفاعلات في ظروف غير قياسية:

   E = E° - (RT/nF) × ln(Q)

   عند 25°C: E = E° - (0.0592/n) × log(Q)

حيث:
• n = عدد الإلكترونات المنقولة
• Q = حاصل التفاعل (باستخدام التراكيز الحالية)

💡 عند الاتزان: E = 0, Q = K
   E° = (0.0592/n) × log(K)
```

### 6. الخلايا التركيزية (Concentration Cells)

```
🔄 نفس المادة في نصفي الخلية لكن بتركيزات مختلفة

💡 E° = 0 (نفس التفاعل في الاتجاهين)

📐 E = -(0.0592/n) × log([dilute]/[concentrated])

🎯 الإلكترونات تتدفق من نصف الخلية الأقل تركيزاً ← الأكثر تركيزاً
```

### 7. التحليل الكهربائي (Electrolysis)

```
🔌 خلية إلكتروليتية: كهرباء ← تفاعل كيميائي (غير تلقائي)

📐 قوانين فاراداي:
1. كتلة المادة المترسبة ∝ كمية الكهرباء المارة
2. الكتلة ∝ الوزن المكافئ للمادة

📐 الحسابات:
   • الشحنة: Q = I × t (كولوم = أمبير × ثانية)
   • مولات الإلكترونات: n_e = Q / F (F = 96,485 C/mol)
   • الكتلة: m = (Q × M) / (n × F)

مثال: كم جرام من النحاس يترسب بمرور 2 A لمدة 30 دقيقة؟
• Q = 2 × 30 × 60 = 3600 C
• n_e = 3600 / 96485 = 0.0373 mol e⁻
• Cu²⁺ + 2e⁻ → Cu ← n = 2
• mol Cu = 0.0373 / 2 = 0.01865 mol
• mass = 0.01865 × 63.55 = 1.19 g
```

### 8. التآكل والحماية (Corrosion & Protection)

```
🔩 تآكل الحديد:
   Anode: Fe → Fe²⁺ + 2e⁻
   Cathode: O₂ + 2H₂O + 4e⁻ → 4OH⁻
   الكلي: 2Fe + O₂ + 2H₂O → 2Fe(OH)₂ ← ثم يتأكسد للصدأ

🛡️ طرق الحماية:
1. الطلاء/الدهان ← عزل عن O₂ والماء
2. الحماية الكاثودية (Sacrificial Anode):
   • ربط الحديد بفلز أكثر نشاطاً (Zn, Mg)
   • الفلز النشط يتأكسد بدلاً من الحديد
3. الحماية الأنودية: تطبيق جهد خارجي
```

## 2. التسمية (IUPAC Naming) - 5 خطوات

```
1. اختر أطول سلسلة كربونية تحتوي على المجموعة الوظيفية الرئيسية
2. رقم من الطرف الأقرب للمجموعة الوظيفية/الرابطة المتعددة
3. سمِّ البدائل (مجموعات جانبية) مع مواقعها
4. رتب البدائل أبجدياً (تجاهل di-, tri-, iso-)
5. اكتب الاسم: [بدائل]-[أصل السلسلة][لاحقة المجموعة]

مثال: 
      CH₃
       |
   CH₃-CH-CH₂-CH₃
   ← 2-methylbutane
```

## 3. أنواع التماكب (Isomerism)

```
🔹 Structural Isomers: نفس الصيغة الجزيئية، ترتيب مختلف للذرات
   • Chain: سلسلة مختلفة (n-butane vs isobutane)
   • Position: موقع مختلف للمجموعة (1-propanol vs 2-propanol)
   • Functional: مجموعة وظيفية مختلفة (ethanol vs dimethyl ether)

🔹 Stereoisomers: نفس الترتيب، اختلاف في الفراغ
   • Geometric (cis/trans): حول رابطة مزدوجة
     - cis: المجموعات المهمة في نفس الجانب
     - trans: المجموعات المهمة في جوانب متقابلة
   • Optical: ذرة كربون غير متماثلة (4 مجموعات مختلفة)
     - enantiomers: صورتان مرآتيتان
```

## 4. تفاعلات أساسية ⭐

### أ) تفاعلات الألكانات (غير نشطة نسبياً)
```
• Halogenation (مع Cl₂/Br₂ + UV): استبدال جذري حر
  CH₄ + Cl₂ → CH₃Cl + HCl
  ← الانتقائية: 3°H > 2°H > 1°H

• Combustion: احتراق كامل
  C₃H₈ + 5O₂ → 3CO₂ + 4H₂O + حرارة
```

### ب) تفاعلات الألكينات (إضافة)
```
• Hydrogenation: H₂/Ni → ألكان
• Halogenation: Br₂/CCl₄ → داي هاليد (يفقد لون البروم ← اختبار)
• Hydrohalogenation: HX ← Markovnikov's Rule:
  "H يذهب للكربون الذي عليه H أكثر"
  CH₃CH=CH₂ + HBr → CH₃CHBrCH₃ (not CH₃CH₂CH₂Br)

• Hydration: H₂O/H⁺ → كحول (Markovnikov أيضاً)

• Ozonolysis: O₃ ثم Zn/H₂O ← يكسر الرابطة المزدوجة ← ألدهيد/كيتون
```

### ج) تفاعلات الألكاينات
```
• تشبه الألكينات لكن تحتاج 2 مول من الكاشف للإشباع

• Hydration (مع HgSO₄/H₂SO₄): 
  Ethyne → Ethanal (enol → keto tautomerism)
  Propyne → Propanone

• Terminal alkynes حمضية قليلاً:
  - تتفاعل مع NaNH₂ ← أسيتايليد
  - اختبار: AgNO₃/NH₃ ← راسب أبيض (لـ terminal فقط)
```

### د) تفاعلات البنزين (استبدال إلكتروفيلي)
```
⚠️ البنزين لا يحدث له إضافة (يفقد الأروماتية) ← يحدث استبدال

| التفاعل | الكواشف | الناتج |
|---------|---------|--------|
| Nitration | HNO₃/H₂SO₄ | Nitrobenzene |
| Sulfonation | SO₃/H₂SO₄ | Benzenesulfonic acid |
| Halogenation | X₂/FeX₃ | Halobenzene |
| Friedel-Crafts Alkylation | RCl/AlCl₃ | Alkylbenzene |
| Friedel-Crafts Acylation | RCOCl/AlCl₃ | Aryl ketone |

🎯 المجموعات الموجهة:
• ortho/para directors (تنشط): -OH, -NH₂, -R, -X
• meta directors (تعطل): -NO₂, -COOH, -CHO, -COR
```

### هـ) تفاعلات الكحولات
```
• Dehydration (مع H₂SO₄/180°C): ← ألكين (Zaitsev: الألكين الأكثر استقراراً)

• Oxidation:
  - 1° alcohol → Aldehyde (باستخدام PCC) → Carboxylic acid (باستخدام KMnO₄)
  - 2° alcohol → Ketone
  - 3° alcohol ← لا يتأكسد (لا H على الكربون الحامل لـ -OH)

• Substitution (مع HX أو PBr₃): ← هاليد ألكيل

• Esterification (مع حمض كربوكسيلي + H⁺): ← إستر
```

### و) تفاعلات الأحماض الكربوكسيلية
```
• Reduction (باستخدام LiAlH₄): ← كحول أولي

• Esterification (مع كحول + H⁺): ← إستر

• Decarboxylation (للأملاح مع soda lime): ← ألكان (يفقد 1 كربون)
  RCOONa + NaOH → RH + Na₂CO₃

• Conversion to acid chloride (مع SOCl₂): ← RCOCl (أكثر نشاطاً)
```

### ز) تفاعلات الإسترات
```
• Hydrolysis:
  - Acidic: إستر + H₂O/H⁺ ← حمض + كحول
  - Basic (Saponification): إستر + NaOH ← ملح الحمض + كحول ← لا رجعة

• Transesterification: إستر + كحول مختلف ← إستر جديد
```

## 5. اختبارات تمييز ⭐

```
| المركب | الاختبار | النتيجة الإيجابية |
|--------|----------|------------------|
| Alkene/Alkyne | Br₂ in CCl₄ | يختفي اللون الأحمر-البني |
| Alkene/Alkyne | KMnO₄ (cold, dilute) | يختفي اللون البنفسجي ← diol |
| Terminal Alkyne | AgNO₃/NH₃ | راسب أبيض (أسيتايليد الفضة) |
| Aldehyde | Tollens' Reagent | مرآة فضية |
| Aldehyde | Fehling's Solution | راسب أحمر (Cu₂O) |
| Methyl Ketone | Iodoform Test (I₂/NaOH) | راسب أصفر (CHI₃) |
| Phenol | FeCl₃ | لون بنفسجي |
| Carboxylic Acid | NaHCO₃ | فوران (تصاعد CO₂) |
| Primary/Secondary Amine | Hinsberg Test | يختلف الذوبان في KOH |
```

## 2. اكتب المعطيات والصيغ قبل الحل
```
📝 مثال:
المعطى: 2.5 g NaOH, V = 250 mL
المطلوب: Molarity

الصيغة: M = mol/L
الحل: 
• mol NaOH = 2.5 / 40 = 0.0625 mol
• V = 0.250 L
• M = 0.0625 / 0.250 = 0.25 M
```

## 3. تحقق من إجابتك
```
✅ هل الوحدة منطقية؟
✅ هل القيمة معقولة؟ (مثلاً: pH بين 0-14، كسر مولي بين 0-1)
✅ هل عدد الأرقام المعنوية صحيح؟
```
